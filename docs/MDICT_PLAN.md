# MDict 状态说明

当前需求不是通用词典管理器，而是让两本指定词典在个人应用中稳定可用。因此 1.2.0 已完成固定词典预转换和内置查询，没有实现运行时 MDX/MDD 导入页面。

已完成：

- Cambridge MDX 2.0 解析与转换。
- Collins MDX 1.2 LZO 解析与转换。
- 重定向和重复词头处理。
- 内存映射二进制索引。
- 前缀建议。
- 两本词典按固定顺序展示。
- 长释义折叠。

未包含：

- 通用 MDX 文件选择和导入管理。
- MDD 图片、CSS、字体和音频。
- 加密词典和所有 MDict 变体。
- 用户动态调整词典顺序。

若以后只继续个人使用，优先保持当前固定索引方案；只有确实需要频繁更换词典时，再增加通用导入和 MDD 资源层。
